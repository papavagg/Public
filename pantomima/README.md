# Παντομίμα 🎭

Παιχνίδι παντομίμας στα ελληνικά με 20.000 ερωτήσεις σε 19 κατηγορίες.
Ανοίγει σε κινητό, τάμπλετ ή υπολογιστή και δουλεύει και χωρίς ίντερνετ.

## Πώς το ανοίγω
- Άνοιξε το `pantomima/index.html` σε browser, ή
- ανέβασέ το σε GitHub Pages και άνοιξε τη διεύθυνση από το κινητό → «Προσθήκη στην αρχική οθόνη».

## Ερωτήσεις
Οι λίστες βρίσκονται στο `data/src/` (μία γραμμή = μία ερώτηση).
Αν αλλάξεις κάτι, ξαναφτιάξε το `data.js` με:

    node pantomima/data/build.js
